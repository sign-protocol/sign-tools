# Operating System

This folder holds the reusable operating system for AI-assisted software delivery.

## Contents
- `product/`: product brief templates and project intent
- `plans/`: active, backlog, historical, and template execution plans
- `decisions/`: ADRs and decision guidance
- `QUALITY.md`: definition of done and verification posture
- `SECURITY.md`: security principles and approval reminders
- `OPERATIONS.md`: operational expectations for deployable systems
- `DECISIONS.md`: when ADRs are required

Keep repo-wide operating artifacts here instead of spreading them across the root.
