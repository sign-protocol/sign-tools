# QUALITY

## Definition Of Done
A task is done only when the applicable items are true:
- requirements are satisfied
- code is readable and maintainable
- tests exist at the appropriate layers
- logs, metrics, and traces are adequate for the risk level
- documentation is current
- ADRs or plans are updated when boundaries or intent changed
- evidence exists for risky or important changes
