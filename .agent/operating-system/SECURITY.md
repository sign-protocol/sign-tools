## Security Principles
1. least privilege
2. secure defaults
3. defense in depth
4. auditable changes
5. no secrets in source control

## Always Stop For Approval
- destructive schema or storage changes
- permission model changes
- encryption or secret-management changes
- new external exposure with real blast radius
- disabling or weakening controls
