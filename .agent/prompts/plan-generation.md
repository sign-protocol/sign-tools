# Prompt Template: Plan Generation

1. link the plan to the relevant requirement or request
2. restate the problem and intended outcome
3. identify assumptions, dependencies, and risks
4. describe architecture, data, security, and operational impact
5. break the work into verifiable steps
6. define tests, evals, and evidence
7. define rollout and rollback when applicable
8. define done criteria
9. call out approval-sensitive steps explicitly
