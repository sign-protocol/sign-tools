# Code Review Rubric

- Is the code aligned with the documented architecture?
- Is the naming clear and intention-revealing?
- Are assumptions and tradeoffs surfaced where they materially matter?
- Is the change larger than it needed to be?
- Does each changed line trace directly to the request, verification, or required documentation?
- Are tests present at the right layers?
- Is observability adequate?
- Would another engineer or agent understand this in six months?
