# Skill Definition Standard

An atomic, distinct, demonstrable capability enabling effective task performance.

## Core Properties

- atomicity | single bounded unit, not a bundle
- observability | demonstrable through performance or outputs

## Include

- single bounded capability
- intentionally developable

## Exclude

- role, task, or job title
- broad capability bundle

## Rules

1. A canonical skill must be observable through behavior or artifacts.
2. Alternate terms shall resolve to one canonical ID.

## Required Attributes

- id | canonical skill identifier
- title | canonical display name

## Optional Attributes

- skillType | technical, interpersonal, cognitive, or physical
