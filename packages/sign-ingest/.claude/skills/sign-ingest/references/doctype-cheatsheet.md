# Doctype Cheatsheet

| Doctype | SIGN type | Best for | Main blocks |
|---|---|---|---|
| `policy` | `pol` | obligations, permissions, prohibitions | `@def`, `@include`, `@exclude`, `@rules`, `@constraints` |
| `standard` | `std` | structured specifications | `@def`, `@props`, `@rel`, `@attrs`, `@disallowed` |
| `adr` | `adr` | architecture decisions | `@def`, `@rules`, `@status`, `@links` |
| `plan` | `pln` | execution plans and roadmaps | `@phases`, `@status`, `@links` |
| `glossary` | `gls` | terms and aliases | `@def`, `@vocab`, `@xwalk` |
| `reference` | `ref` | semi-structured reference material | `@def`, `@props`, `@rel` |
